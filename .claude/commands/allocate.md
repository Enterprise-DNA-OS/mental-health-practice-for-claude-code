Run `node scripts/practice.mjs allocate SESSION-ID --referral="REFERRAL"` after saying back in one line what will change. It writes to the records, so ask before running if the operator has not said yes. Add `--json` when you need to work with the rows.

Present the result as a short table in plain words. Amounts are in the currency shown. Never mix AUD and NZD.
