---
description: Cancel a session and record when the practice was told.
---

Run `node scripts/practice.mjs cancel SESSION-ID [--notified=2026-10-13T08:00:00+11:00]` after saying back in one line what will change. It writes to the records, so ask before running if the operator has not said yes. Add `--json` when you need to work with the rows.

Inside the late-cancel window it shows in /cancellations.

Present the result as a short table in plain words. Amounts are in the currency shown. Never mix AUD and NZD.
