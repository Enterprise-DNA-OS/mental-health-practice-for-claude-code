---
description: Write or update a draft session note.
---

Run `node scripts/practice.mjs note SESSION-ID --text="PRACTITIONER WORDS" --author="PRACTITIONER"` after saying back in one line what will change. It writes to the records, so ask before running if the operator has not said yes. Add `--json` when you need to work with the rows.

Write only what the practitioner dictates. Never add clinical content.

Present the result as a short table in plain words. Amounts are in the currency shown. Never mix AUD and NZD.
